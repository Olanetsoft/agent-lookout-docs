This is the documentation source for Agent Lookout.
It is published with Thally at [agent-lookout.thally.app](https://agent-lookout.thally.app).
The main repository is [github.com/Olanetsoft/agent-lookout](https://github.com/Olanetsoft/agent-lookout).

## Development

- `npm ci` installs the dependencies pinned in `package-lock.json`.
- `npm run check` validates the documentation with the latest Thally CLI.
- `npm run build` builds the site with Next.js.
- `npm start` serves the built site at http://localhost:3040.
- `npm run starter:update` previews an update of the Thally framework, and changes nothing until you add `-- --apply`.
